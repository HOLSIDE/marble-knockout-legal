# marble-knockout-legal

Public legal pages of the Marble Knockout app, published with GitHub Pages
(Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`).

- `privacy.md` / `privacy-en.md`: privacy policy
- `terms.md` / `terms-en.md`: terms and conditions
- `delete-account.md`: how to delete an account (required by Google Play)

The app links to these URLs (`EXPO_PUBLIC_PRIVACY_URL`, `EXPO_PUBLIC_TERMS_URL`). Keep them in line
with what the app actually does; the source of truth for the data processing is the app repo's
`docs/privacy-impact-assessment.md`.
